# Repository publication status

The PSNN repository exists at https://github.com/Hi6795/PSNN. The source
was prepared for public collaboration.

The license has not yet been approved by the project owner. The source is
visible, but contribution/redistribution permissions are not granted until
a license is explicitly selected. MIT is the proposed license.

## Maintainer follow-up

1. Approve the license and add LICENSE in a separate reviewed commit.
2. Review CI and configure branch protection or rulesets for `main`.
3. Enable Issues, Discussions and private vulnerability reporting as desired.
4. Create labels and good first issues based on [ROADMAP](ROADMAP.md).
5. Require PS4 hardware evidence before describing any build as console-ready.

No SDK binaries, proprietary game assets, account credentials or console dumps
should be committed.
