# PSNN Community Code of Conduct

We're building PSNN together. Participants should be respectful, collaborative,
and constructive in issues, pull requests, reviews and discussions.

Harassment, discrimination, threats, personal attacks, doxxing, or deliberately
sharing private console/account information are not acceptable.

Maintainers may remove abusive content and restrict repeat offenders. Until a
maintainer contact is published, report moderation concerns privately to the
project owner rather than posting personal information in a public issue.
